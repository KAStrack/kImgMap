Visual image map
editing made easy.

kImgMap is a zero-dependency JavaScript plugin that replaces a plain textarea with a fully interactive SVG editor — draw, move, resize, and configure HTML imagemap areas with ease.

Zero dependencies UMD · ES module · CommonJS Rect · Circle · Polygon Mouse · Touch · Pen CSS-variable theming ~20 kB gzipped
Example 1

Modal Editor

Default mode. kImgMap hides the textarea and adds an "Edit Image Map" button. Clicking it opens a full-screen modal editor — draw areas, set attributes, then Save.

Parse Existing + Custom Attributes

Pass existing <area> tags in the textarea — kImgMap parses and displays them on open. Use customAttributes to expose any non-standard attributes (e.g. data-value).
